GEOBIM V2.4.0 - GITHUB ALS BRON, CLOUDFLARE PAGES ALS WEBSITE

1. Pak de ZIP uit.
2. Upload ALLE bestanden en mappen naar de hoofdmap van de GitHub-repository geobim.
3. Controleer dat de map functions/api/3dbag aanwezig is.
4. Commit de wijzigingen.
5. Open Cloudflare > Workers & Pages.
6. Maak een Pages-project via Git-integratie.
7. Selecteer de GitHub-repository geobim.
8. Production branch: main.
9. Framework preset: None.
10. Build command: exit 0.
11. Build output directory: public
12. Deploy.
13. Open de nieuwe pages.dev-URL.
14. Controleer dat bovenaan v2.4.0 staat.
15. Test /api/3dbag/health achter de pages.dev-URL.

BELANGRIJK
- Alleen GitHub Pages is statisch en kan de 3DBAG-serverfunctie niet uitvoeren.
- Gebruik voor de werkende app de Cloudflare Pages-URL.
- GitHub blijft de plek waar de bronbestanden staan.
- Er worden geen openbare CORS-proxy's gebruikt.
- 3DBAG wordt alleen per BAG-identificatie opgehaald nadat BAG 2D exact op de getekende contour is gefilterd.

Zie PUBLICEREN_VIA_CLOUDFLARE_PAGES.md voor de volledige uitleg.
