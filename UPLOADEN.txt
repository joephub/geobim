GEOBIM V1.2.0 UPLOADEN

1. Pak deze ZIP uit.
2. Open de GitHub-repository geobim.
3. Kies Add file > Upload files.
4. Sleep ALLE bestanden uit deze map naar GitHub.
5. Laat GitHub de bestaande bestanden vervangen en klik op Commit changes.
6. Laat Settings > Pages staan op Deploy from a branch, main en /(root).
7. Wacht op de Pages-publicatie.
8. Open de website opnieuw. In de titel moet v1.2.0 staan.

Je hoeft de repository niet opnieuw te verwijderen.
